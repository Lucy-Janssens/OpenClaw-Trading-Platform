# OpenClaw Trading Platform - MVP

This repo provides a minimal MVP scaffold with:
- UI (React TS) under `apps/ui`
- API (FastAPI) under `services/api`
- Docker Compose orchestration under `infrastructure`

## Project Structure

```
├── apps/
│   └── ui/             # React/TypeScript Frontend
├── services/
│   └── api/            # Python/FastAPI Backend
├── infrastructure/     # Docker Compose & Env configs
└── ARCHITECTURE.md     # System Design
```
